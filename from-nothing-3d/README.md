# From Nothing — 3D Life Simulator

A browser-based 3D life-sim prototype built with Three.js + Vite.

## Current playable slice

- Third-person WASD movement and sprinting
- Small explorable city block
- Apartment/home interaction
- Diner job interview and repeatable work shifts
- Convenience-store food purchases
- Park NPC conversation/reputation
- Day/night clock
- Cash, energy, hunger, and reputation stats
- Objective progression
- Local browser save/load
- Responsive HUD and pause menu

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated `dist/` folder is deployable to Vercel.

## Controls

- **WASD** — move
- **Shift** — sprint
- **E** — interact
- **Esc** — pause

## Direction

This branch is intentionally a safe prototype inside the existing repository. It does not replace the current life simulator on `main`.
